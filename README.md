# 🤖 Spring AI + Ollama + CodeLlama

A simple **Spring Boot AI Chat Application** using **Spring AI**, **Ollama**, and the **CodeLlama** chat model.

This project demonstrates how to integrate a locally running LLM with a Spring Boot application using Spring AI's `ChatClient`.

* Java 21
* Spring Boot 4
* Spring AI
* Ollama
* CodeLlama
* Maven
* REST API

# 🔟 AgentService

The `AgentService` creates a `ChatClient` using Spring AI.

```java
package com.agent.ollama.services;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.stereotype.Service;

@Service
public class AgentService {

    private final ChatClient chatClient;

    public AgentService(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }

    public String chat(String query) {
        return chatClient
                .prompt(query)
                .call()
                .content();
    }
}
```

### How it works

The service:

1. Receives the user's query.
2. Sends the query to Spring AI.
3. Spring AI communicates with Ollama.
4. Ollama sends the query to CodeLlama.
5. CodeLlama generates the response.
6. The response is returned to the application.

# 1️⃣1️⃣ AgentController

The controller exposes a REST API.

```java
package com.agent.ollama.controller;

import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import com.agent.ollama.services.AgentService;

@RestController
public class AgentController {

    private final AgentService agentService;

    public AgentController(AgentService agentService) {
        this.agentService = agentService;
    }

    @GetMapping("/chat")
    public ResponseEntity<String> chat(
            @RequestParam("query") String query) {

        String response = agentService.chat(query);

        return ResponseEntity.ok(response);
    }
}
```

# 🧩 Why Spring AI?

Spring AI provides abstractions that make it easier to integrate AI models into Spring applications.

Instead of directly handling communication with the LLM, the application can use:

```java
ChatClient
```

For example:

```java
chatClient
    .prompt(query)
    .call()
    .content();
```

This provides a simple API for sending prompts and receiving model responses.

---

# 🦙 Why Ollama?

Ollama allows LLMs to run locally.

Advantages include:

* Local model execution
* No external API required for inference
* Easy model management
* Developer-friendly CLI
* Suitable for local AI experiments
* Can work without sending prompts to a third-party hosted LLM service

# 💻 Why CodeLlama?

This project uses **CodeLlama**, a model designed particularly for coding-related tasks.

It can be used for:

* Java code generation
* Code explanation
* Debugging assistance
* Code completion
* Programming questions
* Technical explanations

# 🛠️ Troubleshooting

## Ollama Connection Error

If you see an error similar to:

```text
Connection refused: localhost:11434
```

Make sure Ollama is running.

Test:

```bash
ollama list
```

Then start the model:

```bash
ollama run codellama
```

---

## Model Not Found

If Spring AI reports that the model does not exist, download it:

```bash
ollama pull codellama
```

Then verify:

```bash
ollama list
```

Also verify:

```properties
spring.ai.ollama.chat.options.model=codellama
```

---

## Port 8080 Already in Use

If port `8080` is already being used, change the Spring Boot port:

```properties
server.port=8081
```

Then access:

```text
http://localhost:8081/chat?query=Hello
```
